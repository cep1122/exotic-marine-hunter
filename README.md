$$\text{MAB (Maximum Allowable Bid)} = \text{Gross Acquisition Ceiling} - (\text{Haul-out/Transport} + \text{Survey Reserve})$$

$$\text{Projected Net Spread} = \text{Market Value} - \text{Total Invested Capital}$$

$$\text{ROI} = \left(\frac{\text{Projected Net Spread}}{\text{Total Invested Capital}}\right) \times 100$$
